# Dushane

**Systems & Backend Engineer** — building deterministic storage engines, cryptographic primitives, and local-first AI runtime infrastructure.

Focused on memory-safe systems programming (`#![forbid(unsafe_code)]`), binary protocol and file-format parsers, fault-tolerant job orchestration, and failure analysis for autonomous agents.

---

### Selected Systems & Research

| Repository | Domain | Architecture & Scope |
| :--- | :--- | :--- |
| [**litewalk**](https://github.com/DushaneW/litewalk) | Storage Internals | Zero-dependency Rust implementation of the SQLite 3 binary on-disk format, B-tree reader, WAL inspector, and 11-stage forensic verifier. |
| [**vaultcore**](https://github.com/DushaneW/vaultcore) | Cryptography | Offline Bitcoin wallet primitives in Rust: BIP-32/39/44/84 key derivation, deterministic UTXO selection, and BIP-143 ECDSA signing. |
| [**agentic-reliability-lab**](https://github.com/DushaneW/agentic-reliability-lab) | AI Reliability | Deterministic evaluation harness, fault-injection runtime, and early-warning ML failure prediction over partial agent trajectories. |
| [**nexus**](https://github.com/DushaneW/nexus) | Local AI / Audio | Cross-platform desktop audio suite (Tauri 2 + Rust process supervisor + FastAPI runtime) for local Kokoro TTS, Whisper STT, and multitrack DSP. |

### Core Focus Areas

- **Storage & Binary Formats** — B-tree indexing, write-ahead logging (WAL), zero-copy deserialization, differential testing, and hostile-input fuzzing.
- **Applied Cryptography** — Hierarchical deterministic key trees, air-gapped transaction signing, consensus parsing, and secret-redacted memory boundaries.
- **Agentic Systems & Runtime Infrastructure** — Sandboxed execution harnesses, trajectory telemetry, Rust-supervised local inference engines, and predictive failure recovery.
